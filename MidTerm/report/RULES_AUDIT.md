## Выполненные ограничения

- Два обязательных метода CBF и Association Rules оценены отдельно, popularity не засчитывается за один из них. Дополнительно реализован и проверен implicit ALS, но в итоговую v2 он не вошёл.
- Ни один просмотр недели 31–42 не используется: доступные логи заканчиваются 26.07.2020. Для каждого исторического среза временной профиль строится после обрезки логов на границе.
- Будущее расписание используется для ID, каналов, начала/конца/длительности эфиров и производного количества эфиров. Это сведения «что, где и когда выходит». Будущие title/category/genre/actors/director/year не участвуют в scoring. Категория для адаптивного веса вычисляется только по прошлому расписанию.
- `tv_show_id=0` не является объектом, меткой или предсказанием. Сырые логи на таком эфире используются только как история канала и времени; это явно раскрыто.
- Пользователи, кандидаты, ground truth, повторные ID, tie-break и функция метрики одинаковы в рамках каждого сравнения. Пересекающиеся rolling-периоды не объявляются независимыми тестами.
- Параметры v2 выбраны и зафиксированы до отправки. Её private score не использовался для выбора этих параметров. Следующие гипотезы также выбираются по исторической валидации; private score используется для отчёта и проверки заданного пользователем численного ориентира.
- Сделаны 2 посылки: private 0.40716 и 0.43003. Это ниже обычного лимита 5 на слайдах и старого 10/day в Overview; форма сервиса перед второй отправкой показывала 99 оставшихся. Не делаем дополнительных посылок без нового обоснованного локального результата.
- Обе посылки скачаны обратно из Kaggle: SHA-256 совпал с соответствующими локальными CSV. Статусы и скриншоты реальны. Никаких A/B-тестов, онлайн-эффектов или влияния на выручку не заявлено.
- Работа индивидуальная: другие участники, субагенты и их решения не использовались. AI-помощь разрешена правилами и раскрывается; внешняя статья Hu–Koren–Volinsky используется с атрибуцией. Код ALS написан в проекте, не заимствован без указания источника.

## Ограничения, которые нельзя скрывать

- Поиск уже широкий, а срезы перекрываются. Числа bootstrap после выбора модели описательные, не доказывают независимую значимость. Полные поисковые таблицы сохраняются, слабые модели не скрываются.
- Абсолютный часовой пояс исходных timestamp не подтверждён; сохранена одна и та же наивная шкала времени без сдвига.
- Скрытый код построения Kaggle-цели не опубликован: слияние фрагментов и tie-break локально заданы, но их точное совпадение с private-разметкой не заявляется.
- Правила домашнего задания противоречат в лимите 5/6 страниц. Для финального PDF выбран строгий предел 5 страниц основного текста плюс источники.
- Репозиторий по просьбе студента пока не публикуется; это нужно завершить до сдачи.
- AI-сессия ещё продолжается. Финальный неизменённый экспорт можно зафиксировать только после всех изменений. Нативный JSONL не подменяется пересказом или искусственным JSON; при техническом запрете расширения в канале курса требуется уточнение у преподавателя.
- Личная проверка AP и личные интерпретации студента получены. Проверки, выполненные агентом, не приписываются студенту; личный перезапуск всего pipeline не заявляется.

## Категория × время суток

Рекомендация студента проверяется как смешанные временные предпочтения аккаунта, без утверждений о возрасте или личности зрителя. `category_context.py` получает только metadata, отфильтрованную до границы. Будущие category/title в SQL scoring не выбираются. Если категория ID известна только из будущего расписания, feature `category_known=0`; cold-start сохраняет общий fallback. Тест проверяет неизменность признаков при замене будущих категорий и добавлении будущих просмотров. Вложенные labels v10 также заканчиваются не позже обучающей границы. Это допустимое расширение гибрида, но его полезность ещё должна подтвердиться расчётом.

Номер внутренней модели не равен числу отправок: v3 CSV подготовлен и проверен локально; на момент запуска v10 в Kaggle всё ещё только две посылки.
